## 2. 条件分位数模型（LightGBM，q0.9 单模型）

目标：r = 签收 − 流入（小时），对数尺度上做分位数回归；T = lag + r̂。
“事后校准”= 每个服务商乘一个系数使约束恰好满足（同窗、无漂移），用来衡量模型的锐度。

| 版本 | 8/25 事后A | 9/3 事后A | 9/12 事后A | 备注 |
|---|---|---|---|---|
| 基础特征（类别 + 时间 + 重量 + lag） | 67.84 | 63.91 | 69.42 | 比服务商常数上限（~111）好 40+ |
| + 历史统计（城市尾程、渠道环节分位数，留一周计算） | 67.77 | 66.80 | 71.13 | 无增益，弃用 |
| + 近况特征（近 3/7 天相对 28 天的偏离，模拟 0–9 天信息滞后） | **64.59** | **63.52** | **67.20** | 三折均提升，保留 |

所需缩放系数在折间波动明显（如 LSP_0007：1.04 → 1.10 → 1.31），说明“上一窗口校准”迁移到下一窗口有较大漂移风险。

两类新特征（11-16 晚，`e11_feats.py`，日志 `work/e11_0912.log`；同口径，单种子基线 66.99，门槛同上）：
- **负荷**：同一渠道、仓×机场×模式、起飞机场、服务商在本包裹流入日之前的完整日历日里流入了多少包裹（含未签收和测试集包裹），以及相对前 14 天日均的偏离。只用流入日之前已结束的日子，所以上线时可得，也避开了测试集 9/30 截断。
- **目的地近况**：服务商 × 目的省份近 3/7 天相对 28 天基线的偏离，做法同 recency.py。

| 尝试 | 得分 | 新特征增益占比 | 结论 |
|---|---|---|---|
| + 负荷（件数与相对偏离，12 个） | 68.10 | 18.9% | 变差 1.1。pinball 反而更低（0.04853），模型大量使用，但学到的"负荷 → 时效"关系迁移不到下一窗口 |
| + 负荷（只用相对偏离，8 个） | 68.54 | 15.2% | 变差 1.6 |
| + 目的地近况 | 66.71 | 5.9% | 好 0.28，未达门槛 |
| + 两者 | 67.24 | 23.3% | 变差 |

解读：负荷与时效的关系不稳定，有的高峰日会变慢，有的大促后反而运力充足。模型把它当成"认出某几天"的标签，在训练期过拟合。这也说明 pinball 更低不代表比赛得分更低，筛选必须用和评分一致的口径。
目的地近况的信息大部分已被"渠道 + 目的省份"类别特征和服务商近况覆盖。

结论：预测层在现有特征下已接近饱和；剩余差距主要来自漂移，而不是模型锐度或模型族。

## 9. 复现核验（11-16）

- 在干净目录（只拷贝 src/、config/、资料包）按 README 从原始 CSV 重跑全流程（95 分钟）：特征与折数据与原目录**逐位一致**；
  但 LightGBM 多线程训练默认不保证逐位可复现（直方图构建方式按计时自动选择、浮点求和顺序随线程调度变化），
  q0.9 预测平均相差 ~2%（三种子平均后 ~1.3%），最终平均承诺 237.96h vs 238.79h。
- 处理一：模型参数加 `deterministic=True, force_col_wise=True`。同一份数据上并发训练的预测完全一致（max|diff| = 0）。
- 但两个目录各自构建的训练数据仍不一致：服务商级近况特征（rc_car_*）相差 1e-14 量级——polars 的并行分组求和在大分组上
  合并部分和的顺序不固定。这点差异足以改变 LightGBM 的分箱/分裂，两目录的 q0.9 预测仍明显不同。
- 处理二：`recency._daily` 改用 numpy.bincount 按行顺序累加（确定性）；两次独立构建的特征逐位一致，与旧值相差 ≤3e-13（实验结论不受影响）。
- 结果：原目录与干净目录同时重跑，9/12 校准窗口预测逐位一致；最终提交比对见下。
- 旧的（非确定性）预测文件保存在 work/nondet_1116/，第一版提交在 outputs/v1_1116/。
- 最终比对：两目录各自完整重跑（同时运行，各 196 分钟），`outputs/submission.csv` 的 SHA-256 完全相同（77c69d54…），
  平均承诺 237.998h、中位 235.05h、最小 78.39h。与确定性修正前的版本（238.79h）的差别属于模型训练的随机波动。
- 同一修正后，LSP_0001 新线路兜底承诺由 306.5h 变为 314.7h（兜底模型重训），新线路保险代价约 1.4h 平均承诺。
